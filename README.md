# PathFinder AI 🚀 

**PathFinder AI** is a career transition tool that uses Generative AI (Gemini 1.5) to map out personalized learning roadmaps. It helps students and professionals bridge the skill gap between their current role and their dream career.

## ✨ Features
- **AI-Generated Roadmaps:** Leverages Google Gemini 1.5 Flash for high-accuracy career pathing.
- **Interactive UI:** A responsive React frontend with a clean, modern "Glassmorphism" design.
- **FastAPI Integration:** A high-performance Python backend for seamless data processing.
- **Production Ready:** Includes robust error handling and secure API key management.

## 🛠️ Tech Stack
- **Frontend:** React.js, Axios, CSS3
- **Backend:** FastAPI (Python), Uvicorn
- **AI Engine:** Google Generative AI (Gemini 1.5 Flash)
- **Environment Management:** Python-Dotenv

## 🚀 How to Run Locally
1. **Clone the repo:**
   `git clone https://github.com/E-Gayathri-Vyshnavi/pathfinder-pro.git`

2. **Backend Setup:**
   - Navigate to `/backend`
   - Create a `.env` file and add: `GEMINI_API_KEY=your_key_here`
   - Run: `pip install -r requirements.txt`
   - Start: `uvicorn main:app --reload`

3. **Frontend Setup:**
   - Navigate to `/frontend`
   - Run: `npm install`
   - Start: `npm start`# PathFinder AI 🚀
